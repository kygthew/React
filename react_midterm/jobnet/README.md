# JobNet — Job Search App

#About the Project

JobNet is a React web application that helps students and beginners find job opportunities and internships.

Users can browse jobs, search for vacancies, filter results, and view job details. They can also add their own job listings.

# Features

- View job vacancies from a public API.
- Search jobs by title or keywords.
- Filter jobs by type and other available options.
- View job details.
- Add your own job vacancies.
- Save user-created jobs in the browser using localStorage.
- Responsive design for different screen sizes.

# Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
- Arbeitnow Job Board API
- localStorage

# How to Run the Project

# 1. Download the project

Clone the repository or download the project files from GitHub.

# 2. Install dependencies

Open the project folder in a terminal and run:

```bash
npm install
```

# 3. Start the application

Run:

```bash
npm run dev
```

Open the local URL shown in the terminal, usually `http://localhost:5173`.

# API

JobNet uses the public Arbeitnow Job Board API to load job vacancies.

API URL: https://www.arbeitnow.com/api/job-board-api

An internet connection is required to load vacancies from the API.

# Data Storage

User-created job vacancies are saved in the browser using localStorage.

This means the vacancies remain available after refreshing the page in the same browser. They are not shared between different users or devices.
